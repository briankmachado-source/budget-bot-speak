# Smart Money Assistant

Quiero crear una aplicación con asistente de voz estilo Alexa enfocada en finanzas personales. Debe permitir interactuar por comandos de voz como "hola registra pago por $400,000 de verduras" y que el asistente ejecute la acción de hacer el registro automáticamente, organizando montos, categorías y transacciones en un panel financiero.

This project was built with [Lovable](https://lovable.dev).
